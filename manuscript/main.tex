\begin{abstract}
S4D-TAM (Semantic 4D Token Attention Map) is a navigation architecture for unmanned aerial vehicles operating in Global Navigation Satellite System-degraded environments. The system converts multimodal observations into a persistent set of semantic four-dimensional tokens that encode geometry, semantics, dynamics, observation history, and calibrated uncertainty. A hierarchical spatiotemporal transformer updates this representation, supports alignment with reference maps, and predicts occupancy beyond the current field of view. The resulting world model is coupled to a planner that trades path risk, energy expenditure, and information value. The central hypothesis is that persistent tokenized spatial memory can reduce redundant image processing and improve robustness relative to navigation pipelines that rely predominantly on instantaneous observations. The manuscript formalizes the representation and inference process and defines a reproducible evaluation protocol covering trajectory accuracy, robustness under degraded positioning, map quality, predictive occupancy, computational cost, and mechanism-level ablations. External comparisons target established visual, visual-inertial, and lidar-inertial baselines on public aerial-robotics datasets. Confirmatory claims will be reported only after the frozen benchmark matrix and representative field or field-analog validation have been completed.
\end{abstract}
