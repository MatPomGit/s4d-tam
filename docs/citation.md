# Citation

Citation metadata for S4D-TAM is maintained in [`CITATION.cff`](https://github.com/MatPomGit/s4d-tam/blob/main/CITATION.cff).

Use the citation information associated with the exact software release used in an experiment. For reproducible scientific reporting, record the repository revision or release tag together with dataset versions, configuration files and run manifests.

GitHub can render the repository citation metadata directly from `CITATION.cff` through the **Cite this repository** interface.
